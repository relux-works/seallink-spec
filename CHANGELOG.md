# Changelog

All notable changes to the SealLink Protocol Specification are documented in this file.

## [1.0.0-draft.2] - 2026-11-22

Modular draft of the SealLink v1.0 Protocol Specification with executable Tier 1 verifier coverage and Namecoin Core `nc28.0` P2A regtest evidence:

- **Normative Core Specifications (`spec/SPEC-00` through `spec/SPEC-07`):** Architecture, Restricted RFC 8785 JCS wire format, universal `SignatureSet` / `guardian_approvals[]` policy binding, 7-predicate Constraint Algebra, Namecoin Core `nc28.0` ledger binding (`NAME_NEW` / `NAME_FIRSTUPDATE` / `NAME_UPDATE`, `ScriptPolicy`, Merkle batch `0x02`, TRUC v3 / `P2A` CPFP), 520-byte multi-role identity with on-chain role-policy pins and pinned `NamePin` providers, eternal origin certificates with salted privacy commitments, explicit `disposer_pk`/`arbiter_pk`/`challenger_pk`, authenticated `status_seal` / `roster_seal` / `recovery_seal` continuation spines, direct initial (`0x12`) and acyclic two-stage (`0x0d`/`0x0e`) guardianship, roster transitions (`0x0f`), 4-class linear verifier-derived quorums, structural consistency invariants (`SL-ORIG-016`), N-party salted contracts (`ward_origin_id`, `machine_clause_indices`) and symmetric `seallink-assent/1`, universal grants with R8.5/R8.6 depth-2 re-delegation, acyclic single-use consumption (`0x11`), recipient-authenticated admission pipeline, crash-in-effect-window `uncertain` recovery, fenced anti-rollback journals, and replaceable service portability.
- **Standard Profiles (`profiles/`):** `PROFILE-mail-v1.md` (`mail`) and `PROFILE-agent-v1.md` (`agent-session`, including normative `strict_drop` `agent/guardian-message` under `event_class = "effect_grant"`), backed by closed argument and result JSON Schemas.
- **Machine-Readable SSOT (`registry/`, `schemas/`):** 6 JSON registries (30 object types, 22 key roles, 84 refusal codes, 18 `SLNK` `OP_RETURN` action definitions `0x01`–`0x12` with `0x06` reserved, 8 standard service types, 7 Constraint Algebra predicates) and 12 Draft 2020-12 JSON Schemas with versioned draft `$id` URIs.
- **Executable Conformance Vectors & Reference Verifier (`vectors/`, `tools/`, `conformance/`):** 8 vector suites (unit vectors, 4 full RFC 8448-style traces including ward agent guardian intake and crash-in-effect-window recovery, and an executable `84/84` refusal coverage matrix), pure-Python reference Tier 1 verifier (`tools/seallink_verifier.py`) executed end-to-end inside `tools/speclint.py`, and two-node Namecoin Core `nc28.0` `P2A` 1p1c regtest evidence (`conformance/p2a-regtest/`).
- **Governance & Tooling:** `CONFORMANCE.md`, `OPEN-QUESTIONS.md`, `SLIP-TEMPLATE.md`, `guides/GUIDE-01-custody-and-signers.md`, `archive/rule-inventory.md`, single-file Markdown bundle builder (`tools/build_bundle.py`), and GitHub Actions CI/Release pipelines.
