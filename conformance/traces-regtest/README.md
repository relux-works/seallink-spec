# Namecoin Core 28 — Live Seven-Trace Cold-Observer Regtest Conformance Proof for SealLink

End-to-end live Namecoin Core `v28.0.0` regtest execution of all seven SealLink protocol conformance traces (`trace-01` through `trace-07`, **51 live `Tier1Verifier` verdicts**, `final_tip_height: 660`) under strict standard transaction policy (`-acceptnonstdtxn=0`, `-txindex=1`, `-namehistory=1`), with every `ChainView` constructed by a brand-new stateless **`ColdNamecoinObserver`** (`tools/nc_rpc_adapter.py`, verified against the closed Draft 2020-12 `ChainViewSnapshot` schema) querying **strictly the independent read-only peer node (`node B`, `-disablewallet=1`, dedicated 9-method `rpcwhitelist` user with `-rpcwhitelistdefault=0`)** with zero writer-side state, and verified live through the Reference Verifier Core (`tools/seallink_verifier.py`, `Tier1Verifier(pinned_network="regtest", require_jsonschema=True, require_observation_bracket=True)`).

## Measured Configuration & Honest Boundary of Inputs

- **Nodes:** Two fresh upstream Namecoin Core `v28.0.0` (`nc28.0`) regtest daemons running on separate temporary data directories, standard policy (`-acceptnonstdtxn=0`), transaction and name-history indexes enabled (`-txindex=1 -namehistory=1`), connected strictly over a single loopback link (`127.0.0.1`) with an **outbound connection from Node A -> Node B** (avoiding inbound peer inventory trickle delays) and generous `180 s` propagation timeouts, with no other peers.
  - **Node A (writer):** Broadcasts raw signed transactions, builds `createpsbt` + `namepsbt` `P2WSH` name updates, submits TRUC v3 `P2A` CPFP revocation packages via `submitpackage`, and mines regtest blocks.
  - **Node B (independent read-only verifier peer, `-disablewallet=1`, `-rpcwhitelistdefault=0`):** Receives zero RPC submissions; observes all transactions over P2P (mempool and confirmed blocks) and supplies 100% of ledger facts to `ColdNamecoinObserver` through a dedicated read-only RPC credential (`seallink_obs`) strictly limited by `rpcwhitelist` to the exact 9 read-only methods `getblock,getblockchaininfo,getblockhash,getblockheader,getindexinfo,getrawmempool,getrawtransaction,gettxout,name_history` (verified live on startup to reject `sendrawtransaction` with HTTP 403), cross-checked against Node A as the comparison peer.
- **Cold Observer Input Boundary (`tools/nc_rpc_adapter.py`):**
  - **From Node B RPC ONLY:** opening and closing snapshot brackets (`getblockchaininfo` measured before and after every observation -> `observation_bracket` & `rebracket_tip`, with `retry_on_tip_change` support and closed-bracket `pre_effect_recheck` before side effects), block tips/headers (excluding invalidated/reorged blocks via active-chain checks, plus BIP-113 `mediantime` for quiet maturity heights `h_rec + delay_blocks` and real `CAuxPow` + `SegWitNameUpdateProof` block extraction via `getblock`), confirmed heights, raw transactions (`nVersion` preserved), BIP-141 witnesses (deriving P2WPKH `owner_policy` and `SIGHASH_ALL` sighash bytes), live UTXO liveness (`gettxout(..., include_mempool=True)`), mempool and confirmed spend chains, `SLNK` `OP_RETURN` frames (`0x01`–`0x14`), `(seal_txid, seal_vout + 1)` grant-issuance linkage coins, exact signed continuation output indices (`pending_vout`, `active_vout`, `next_roster_vout`, `new_vacant_vout`, `next_status_vout`, `next_recovery_vout`, `next_log_vout` — no hardcoded `0`/`1` heuristic), and complete multi-registration `name_history` lineages partitioned at each `OP_NAME_FIRSTUPDATE` (including per-lineage `first_error_height` isolation so alien legacy `P2PKH` re-registrations never taint earlier lineages).
  - **Clock Mode Separation:** Regtest traces explicitly run with `clock_mode="regtest_deterministic"` (deriving freshness `local_now_unix` and `tip_first_seen_unix` deterministically from the regtest block header timestamp so mined regtest bursts stay reproducible), strictly separated from `clock_mode="operational"` (which uses real UTC wall-clock time and persists `clock_watermark` and `first_sight_by_hash` via file-locked transactional state merge to `state_path`, tested in `tools/nc_rpc_adapter.py` offline self-tests).
  - **From untrusted wire objects (strictly verified against Node B):** off-chain manifests (checked against on-chain `SHA256(bytes) == m.h`) and `ScriptPolicy` preimages carried in `NamePin`/`Seal`/`Origin` wire fields (checked byte-for-byte against Node B's on-chain `scriptPubKey` hex before inclusion).
- **Cryptography & Transactions:** Zero external crypto pip dependencies — pure-Python RFC 6979 low-S DER secp256k1 ECDSA + BIP-143 SegWit v0 signing paired with repository `tools/seallink_ref.py`, `tools/seallink_verifier.py`, and `tools/nc_rpc_adapter.py`.

## Reproduce

Requires Python 3.11+ with `jsonschema>=4.23` and official Namecoin Core `v28.0.0` (`nc28.0`) binaries (`namecoind` and `namecoin-cli`).

```sh
python3 conformance/traces-regtest/run_traces_regtest.py \
  --bin-dir /absolute/path/to/namecoin-28.0/bin \
  --output-json /tmp/observed-traces.json
```

All raw transaction hexes, txids, witnessScripts, negative-control rejection reasons, cold-observer lineage counts, peer observation flags, and `Tier1Verifier` verdicts from our reference run are recorded in [`observed-traces.json`](observed-traces.json) (with the standalone offline Trace 07 real mined Tier-2 SPV fixture in [`trace-07-tier2-spv-fixture.json`](trace-07-tier2-spv-fixture.json)) and integrity-pinned in [`SHA256SUMS`](SHA256SUMS). Both regtest daemons are stopped cleanly and all temporary data directories are removed on exit.

*(Note: `conformance/p2a-regtest/` remains untouched as the original standalone two-node `P2A` package-relay control artifact.)*
